## [S1] Problem

教师备「人教版七下第1课《隋朝统一与灭亡》」微格课/常规课时，需要多套可直接照讲的课堂导入脚本，以便按班情、时长与展示条件选用。项目内已有 PPT 导入以「盛世之问」「柏杨评价」为主，覆盖面不够，缺少按常见导入类型组织、可对比选用的完整话术文档。

## [S2] Design

交付一份 Markdown 设计文档（主产物），内含 **6 套**互不重复的导入方案，覆盖常见历史课导入类型：

| # | 类型 | 核心钩子 | 主要锚点 |
|---|------|----------|----------|
| A | 问题悬念 | 38 年王朝 vs 千年遗产 | 教材主问题、短命与深远 |
| B | 诗词材料 | 皮日休《汴河怀古》 | 教材卷首诗、功过双问 |
| C | 图像文物 | 含嘉仓 / 大运河今貌 | 仓窖遗址、运河实景 |
| D | 联系现实 | 今天仍在用的大运河 | 京杭运河、南水北调语境 |
| E | 情境体验 | 征夫 / 使者第一人称 | 徭役、流求、民力代价 |
| F | 读图设问 | 运河为何南北走向 | 教材「想一想」、地势与水系 |

每套方案必须包含：

1. 类型标签与适用场景（微格课 / 常规课）
2. 建议时长（3–5 分钟）
3. 设计意图（对接课标/教材哪一问）
4. 所需素材清单（可复用项目已有 assets 或纯话术）
5. **完整教师话术**（开场句 → 推进 → 追问 → 收束，可直接照讲）
6. 学生预期反应与追问应对
7. 板书 / 投影建议（一句话即可）
8. 衔接正文路径（如何转入「隋的统一」或全课主线）
9. 优缺点与选用建议

文档另含：

- 开篇选用速查表（一页对比）
- 结尾「如何选」决策建议
- 与现有 `intro.pptx` 两种导入的关系说明（互补不重复）

约束：

- 史实以人教版七下第1课教材表述为准；拓展材料须标明
- 语言面向七年级，口语可讲，不堆学术黑话
- 不改动现有 PPT / 网页讲义文件；本次只新增文档

## [S3] Out of Scope
