15. 结束：课后讨论

### 地图操作契约

- **先修复**：点「染色 / 标点」后，相关区域在完整全景图上以 0.6–0.9s 过渡完成上色或出现标记。
- **再放大**：仅在修复动作完成后，「放大此处」按钮才可用；放大到该区域局部（scale≈2.2），再点可还原。
- 基图为内置 SVG 示意（非比例），572/612 实拍图作对照页保留。

### 技术

- 单文件改写 `web-lessons/sui-lesson1-player.html`，沿用左侧时间轴 + 整页翻页。
- 动画：transform / fill / opacity，无外部库。
