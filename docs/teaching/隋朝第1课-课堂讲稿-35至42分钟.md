## 一、封面导入（约 3 分钟）

**【翻页】封面 →「开启这段历史」→ 导入节点**

**讲：**  
同学们，今天我们学习《中国历史》七年级下册第 1 课——隋朝统一与灭亡。

上课之前，先请大家记两个数字。第一个数字是 **37**，第二个数字是 **1300**。

**【翻页】导入 ·「37 年的王朝，何以影响千年？」**

**讲：**  
37，是隋朝的国祚。从 581 年杨坚代周建隋，到 618 年隋炀帝在江都被杀，只有三十七年，前后两位皇帝。1300，是科举制从创立到清末废除，大约延续了一千三百年。

一个只存在三十七年的王朝，凭什么影响此后一千三百年？  
它结束了自西晋末年以来二百七十多年的分裂；它开凿了当时世界上最长的大运河，全长二千七百多千米；它确立的三省六部和律令体系，深刻影响了此后千余年的中国。

**【翻页】皮日休《汴河怀古》**

**讲：**  
唐人皮日休写道：「尽道隋亡为此河，至今千里赖通波。若无水殿龙舟事，共禹论功不较多。」  
有人说隋朝亡就亡在这条河上，可直到今天，千里交通还靠这条水路。如果没有龙舟巡游那样的奢靡，它的功劳可以和大禹相比。

功与过、兴与亡，从开篇就拧在一起。本课主问题只有八个字：**何以兴？何以亡？**

**板书：**  
```
37        1300
何以兴？  何以亡？
```

**讲：**  
下面沿着时间线，从 577 年说起。

## 二、北方整合与建隋（约 6 分钟）

### 2.1 577 北周灭北齐

**【翻页】左侧时间轴点「577」→ 地图**

**讲：**  
先看地图。当时北方长期东西对峙：西边是宇文氏**北周**，东边是高氏**北齐**，长江以南是**陈**。

北周武帝整顿军旅，国力反超。575 年首次东征，576 年攻下晋阳，**577 年进入邺城，北齐灭亡**。

**问：** 北方合并之后，哪一方的压力骤然增大？

**【翻页】北方一体意味着什么**

**讲：**  
关键不在打仗打赢，而在于：分裂已久的北方人口、粮仓、军队、工匠，**第一次被同一个政权集中调度**。这是四年后隋能代周、又过十二年能渡江灭陈的物质前提。

**【翻页】关陇集团与禅代逻辑**

**讲：**  
再补一个背景概念：**关陇集团**。从西魏、北周到隋和唐初，统治核心是一群以关中为根据地、胡汉融合的军事贵族。杨坚代周，不是草民起义推翻旧朝，而是**这个集团内部的权力再分配**。所以隋初能很快沿用前朝官僚和制度；同时也把门阀贵族的利益带进了新王朝——这为后来为什么要搞科举埋下了伏笔。

### 2.2 581 杨坚代周建隋

**【翻页】时间轴「581」→ 地图 → 杨坚代周建隋（文帝像）**

**讲：**  
北周末年，外戚**杨坚**执掌朝政。581 年，他夺取北周政权，建立隋朝，**仍以长安为都**，就是**隋文帝**。

权力从哪里来？杨坚的长女是北周宣帝皇后。580 年宣帝去世，静帝年幼，杨坚以外戚身份辅政，迅速掌握军政大权。尉迟迥等人「三方之乱」被韦孝宽平定后，再无人能阻止政权更替。

有意思的是国号：其父杨忠受封「随国公」。「随」有走之旁，寓奔走不宁，即位后去掉走之旁，定国号为**「隋」**，改元**开皇**。

**讲：**  
请同学们记住：这一年变的是政权名号，北方疆域并没有大变。真正难换的不是国号，而是制度和社会的整合。

**【翻页】「开皇」年号与治国姿态**

**讲：**  
年号「开皇」，有开辟皇统之意。文帝施政：节俭、勤政、亲理细务、严行考核。他把财政和人力从贵族手里更多收归国家直接掌握的编户——这既是开皇富强的内核，也是后来炀帝能「超常透支」的体制基础。

### 2.3 583 迁都大兴城

**【翻页】时间轴「583」→ 地图（标注两京）→ 营建并迁都大兴城**

**讲：**  
建立隋朝两年后，迁都**大兴城**。旧长安「凋残日久，屡为战场」，文帝命宇文恺在龙首原南侧重新规划：宫城、皇城在北，中轴对称，南面棋盘式里坊和东西市。地面上的秩序，就是国家政治秩序的投影。

**讲：**  
这里埋一条线：关中是政治根本，但粮食不够吃，必须靠东方转输。后来为什么营建洛阳、开凿运河？答案已经写在迁都的选择里。

**板书：**  
```
577 北方一统 → 581 建隋 → 583 迁大兴
```

## 三、589 灭陈统一（约 4 分钟）

**【翻页】时间轴「589」→ 地图（隋形势）**

**问：** 南北实力已经谁强谁弱？

**【翻页】陈后主与南朝末局**

**讲：**  
陈是南朝最后一个王朝，疆域人口都远逊北方。陈后主有文才，政治军事却松弛：倚重近臣、大修宫室、边备松懈。长江天险要真正成为防线，需要水军舟船、统一指挥、沿江补给——陈朝三样都在失分。

隋朝则系统备战：积粮造船，沿江骚扰消耗陈军船只，招降与威慑并用。589 年的统一，不能讲成「隋军一到、望风而降」。

**【翻页】渡江灭陈，全国一统**

**讲：**  
588 年冬，隋以杨广为行军元帅，大军分路并进。589 年正月，贺若弼、韩擒虎等相继渡江，攻入建康，陈后主被俘。

**教材结论必须落实：589 年，隋军渡过长江，灭掉陈朝，统一全国。** 自西晋末年以来二百七十多年的分裂，到此结束。

**【翻页】统一意义：两层评价分开**

**讲：**  
统一的意义，教材说得清楚：结束了长期分裂，顺应了统一多民族国家交融发展的大趋势，促进了南北经济文化交流。

但请注意两层评价要分开：**结束分裂是历史之功；统一之后如何对待民力，是另一重问题。** 功与过可以并存，不能互相掩盖。

没有政治统一，就没有全国性的大运河，也没有全国性的科举。从建隋到灭陈只用了八年——真正难的是统一之后。

**板书：**  
```
589 统一全国
功：结束分裂
问：民力向何处用？
```

## 四、开皇之治（重点，约 9 分钟）

**【翻页】时间轴「604」→ 开皇之治总述（文帝像）**

**讲：**  
现在进入本课制度重点：**开皇之治**。

教材怎么概括文帝？发展经济；**编订户籍，核实户口**；减轻百姓赋役负担；统一币制和度量衡；加强中央集权；修订和减省刑律；简化机构，提高行政效率。结果是经济迅速恢复，人口和垦田大幅增长，成为国力强盛的王朝。史家称为「开皇之治」。

**讲：**  
这些不是孤立的「好政策」，而是一条咬合的链条：先通过户籍掌握人口 → 赋役征收稳定 → 仓库充实 → 才有条件减负，也有余力修订制度、支撑统一战争。

### 4.1 三省六部（约 3 分钟）

**【翻页】三省六部：决策如何被拆开 → 架构图**

**讲：**  
中央行政，记住一句话：**中书出令、门下审核、尚书执行、六部办事。**

- 皇帝最终裁决  
- **内史省**（隋因避讳改称，唐恢复叫中书省）：草拟诏令  
- **门下省**：审核、可以**封驳**退回  
- **尚书省**：统领施政，下管六部——吏、户、礼、兵、刑、工  

制度用意有三：决策、审议、执行分开，避免一人独揽；三省都对皇帝负责，便于集权；六部分工专业化，提高效率——正对应教材「加强中央集权、简化机构、提高行政效率」。

**【翻页】课堂活动：一项政令怎样走完**

**讲：**  
我们用一个案例走一遍。假设开皇年间要在关东增置官仓、调粮入京：

1. 皇帝因关中粮价不稳，提出增储；  
2. **内史省**起草诏书：地点、数额、期限、责任人；  
3. **门下省**审核——若认为征调过重、妨碍农时，可以**封驳退回**；认可则副署生效；  
4. **尚书省**奉诏分派：户部核账，工部造仓，兵部保漕路，吏部考核；  
5. 进度回报，重大事项再奏闻皇帝。

**问：** 封驳是在牵制皇权，还是在替皇帝纠正失误？

**讲：**  
本质是**用程序减少施政失误**，不是拆散皇权。皇帝仍作最终裁决，但政令要过三道程序、六个专业部门。  
（可安排三名学生分饰内史、门下、尚书，故意让门下驳回一次。）

### 4.2 户籍：大索貌阅与输籍定样（约 2 分钟）

**【翻页】大索貌阅与输籍定样**

**讲：**  
户籍是赋役的基础。分裂久了，户口隐漏严重：有人诈老诈小逃避赋役，有人托庇豪强当「荫户」。

两项配套措施：

- **大索貌阅（585）**：全面清查户口，当面核对年龄体貌；不实者里正、党长治罪；大功以下亲属分立户头。一次清查新增四十余万丁、一百六十余万口。  
- **输籍定样**：中央制定各等人户赋役标准样册，颁行诸州，每年正月依样定户等，地方难再乱加码。

**讲：**  
一句话：**一个扩户口，一个定税则。** 板书「查户口—定户等—稳课役」。  
问：为什么「减轻赋役」要先从查户口做起？  
答：先把税基做实，减负才不是无源之水。

### 4.3 三柱与总结（约 2 分钟）

**【翻页】开皇律 → 租调·府兵·开皇律 → 合力与伏笔**

**讲：**  
户籍之后，三根柱子撑起开皇：

1. **租调制**（经济）：均田授田，农民交租、调，服力役；「岁役功不过二十日，不役者收庸」。  
2. **府兵制**（军事）：兵农合一，军权归中央；590 年诏军人属州县，兵农户籍合一。  
3. **开皇律**（法律）：十二篇；五刑——笞、杖、徒、流、死；「十恶」常赦不免；废除若干酷刑。是《唐律疏议》的直接蓝本。

**【翻页】合力与伏笔**

**讲：**  
收束开皇之治：统一提供前提，户籍与租调提供财力人力，三省六部、府兵、律令立起框架——**足以兴**。  
配套还有统一币制度量衡、黎阳仓等仓储漕运，**并非炀帝首创**。

**伏笔必须讲透：** 成就开皇之治的，和后来被炀帝用来超常征发的，是**同一套高效国家机器**。文帝用它休养积蓄；炀帝用它无限透支。制度好不好，和掌权的人怎么用，要分开评价。

**板书：**  
```
开皇之治
三省六部｜户籍｜租调·府兵·律
足以兴 → 也可能足以亡
```

## 五、605 炀帝继位（约 3 分钟）

**【翻页】时间轴「605」→ 夺嫡与继位（炀帝像）→ 施政心理**

**讲：**  
604 年文帝去世，杨广即位，就是**隋炀帝**。

储位之争：杨广原是晋王，兄长杨勇是太子。杨勇奢华，与独孤皇后和部分重臣关系紧张；杨广刻意表现俭朴孝谨，交结杨素。600 年，杨勇被废，杨广为太子。

继位过程：正史与后世传闻层累不一，「弑父」「矫诏」等说法**不能当作确凿史实**。可以确定的是：他迅速控制中枢，处死杨勇，清洗异己。

**讲：**  
更重要的不是宫斗戏，而是**施政心理**——教材八个字很准：**急功近利，不恤民力**。

可拆成四条：  
1. **功业冲动**：想在短时间内同时完成东都、运河、巡游、对外武功；  
2. **过高自评**：自恃承接文帝厚实基业；  
3. **反馈失灵**：不愿被谏诤打断工程节奏；  
4. **路径依赖**：每动员得手一次，就觉得「还能再征发一次」。

**问：** 这些工程本身或许都有道理，为什么仍然不免亡国？  
（引导：目的合理 ≠ 动员方式可以无限透支。）

**板书：**  
```
文帝：先查户口，再减赋役
炀帝：先排工程，再强征人力
```

## 六、科举（重点，约 5 分钟）

**【翻页】时间轴「607」→ 九品中正制为何被废**

**讲：**  
选官制度，先看旧制。魏晋南北朝主要行**九品中正制**：中正品评人物，授官越来越看家世。日久形成「**上品无寒门，下品无势族**」，中央难以直接掌握选官入口。

隋文帝开皇年间**罢九品中正**，强调依才能授官。《通典》说得很明白：「九品及中正，至开皇中方罢。」

**【翻页】开创科举取士制度 → 进士科流程**

**讲：**  
**隋炀帝设置进士科**，以考试选拔人才，**科举制由此创立**。这是教材必讲结论。

要讲清表述分寸：科举是一个**过程**——文帝打破门阀垄断，炀帝设进士科标志成型，唐宋趋于完备。课序上取 607 年便于排时间轴，教材则表述为「隋炀帝时」。

**【翻页】进士科：以时务策取士**

**讲：**  
早期进士科考什么？主要是**时务策**：围绕治国、边防、吏治、农桑等现实问题书面作答，考察见识和分析能力。

**易错点，请记牢：** 隋代进士科**不等于**背四书五经、写八股文。那是后世演变，不能倒推到隋朝。

**【翻页】科举制的历史意义**

**讲：**  
教材概括科举影响，可用五句话：

1. 选官制度的重大变革；  
2. 加强朝廷选官之权；  
3. 扩大统治基础；  
4. 促进社会阶层流动；  
5. 提高官僚队伍文化素养。  

一直延续约 **1300 年**，到 1905 年才废除。

**问（三问串联）：** 九品中正问「出身何家」；科举问「考得如何」；最终由谁定夺？——**中央，由皇权定夺**。

**讲：**  
科举与隋末暴政同时并存，恰恰说明：**制度遗产可以穿越王朝自身的寿命。**

**板书：**  
```
门第 → 才识
九品中正 → （文帝废）→ 进士科
```

## 七、大运河（重点，约 7 分钟）

**【翻页】时间轴「610」→ 营建东都洛阳**

**讲：**  
605 年起，营建**东都洛阳**，与长安形成两京格局。洛阳居天下之中，靠近关东财赋和漕运，便于控山东、江淮。战略上并不荒谬；但每月役使民夫数十万，是「不恤民力」的早期标志工程。

**【翻页】开通大运河 → 分段示意图**

**讲：**  
教材重点：为加强南北交通、巩固统治，隋炀帝征发几百万人，从 605 年起开凿贯通南北的大运河。

- **中心**：洛阳  
- **北端**：涿郡（今北京一带）  
- **南端**：余杭（今杭州）  
- **水系**：海河、黄河、淮河、长江、钱塘江五大水系  
- **规模**：全长 **2700 多千米**，当时**世界上最长的运河**

**四段记时间：**

| 段 | 年 | 方向 |
|----|----|------|
| 通济渠 | 605 | 洛阳—淮水 |
| 邗沟 | 605 | 淮水—江都 |
| 永济渠 | 608 | 黄河—涿郡 |
| 江南河 | 610 | 京口—余杭 |

永济渠之后史载「**丁男不供，始以妇人从役**」——男丁不够，妇女也去服役，民力透支已经写在史书里。

**【翻页】为何是南北走向**

**问（教材想一想）：** 我国地势西高东低，大河多自西向东，为什么大运河是南北走向？

**讲：**  
政治军事中心在北，经济重心逐渐南移，缺的是**南北纵向联系**。人工运河把五大东西向水系缝成一张网，补上「东西通、南北阻」的缺口。

**【翻页】漕运与转漕**

**讲：**  
运河不是观光水道，是帝国的**粮食供应链**：江南粮 → 运河四段 → 洛阳诸仓（含嘉仓等）→ 永济渠 → 涿郡前线。  
永济渠北通，还直接服务对高句丽方向的后勤——这既解释 612 年何以能动员大军，也解释一旦战败财政为何见底。

**【翻页】巡幸江都 → 皮日休**

**讲：**  
教材还写：多次巡游，乘坐高大华丽的龙舟，随行船舰浩浩荡荡，**仅拉纤民工就多达数十万**。605、610 两下江都；610 年还派人经略**流求**（今台湾）。

巡游不能简单说成玩乐，也不能美化成纯政治巡视——它是**政治展示 + 工程检验 + 极致铺张**三者合一。

回到皮日休：「尽道隋亡为此河……若无水殿龙舟事，共禹论功不较多。」  
**评价要分开：** 短期是征发与民苦，长期是南北通道与后世影响。

**板书：**  
```
大运河 605–610
洛阳中心｜涿郡—余杭｜2700+ km
功在千秋 ≠ 建设过程无代价
```

## 八、征辽、起义与落幕（约 5 分钟）

**【翻页】时间轴「614」→ 三次征辽东**

**讲：**  
教材称「三次征辽东」，对象主要是**高句丽**（不能笼统说成「朝鲜」）。

- **612**：动员空前（史书形容倾国之众，运输民夫又是军队两倍），萨水惨败；  
- **613**：二征中，杨玄感后方起兵，被迫撤军；  
- **614**：三征，高句丽请降，战略目标并未真正解决。

**时间辨析：** 起义首发不是在 614 年战败之后。**611 年**，王薄已在山东长白山起事——点燃起义的，是**为战争先行压下的沉重徭役**。

**【翻页】李密传材料 → 暴政与民不聊生**

**讲：**  
材料研读：「父母不保其赤子，夫妻相弃于匡床，万户则城郭空虚，千里则烟火断灭。」——《旧唐书·李密传》。  
相关史事还有「**福手福足**」「煮土而食」，起义檄文「罄南山之竹，书罪无穷」。

**教材因果链：**  
急功近利、不惜民力 → 每年征发大批劳动力 → 百姓无法正常生产 → **民不聊生，社会矛盾激化** → 大规模农民起义。起义首先爆发在深受徭役之苦的今**山东**地区。

**【翻页】杨玄感起兵**

**讲：**  
613 年，权臣杨素之子**杨玄感**起兵，很快失败，意义却大：统治集团内部公开反叛，对应教材「一些隋朝官员也趁机起事」。局势从「朝廷对农民」变成「朝廷对农民、贵族、地方官」的总崩塌。

**【翻页】时间轴「615」雁门之围**

**讲：**  
615 年北巡，突厥围炀帝于雁门。规模不是最大，却是总暴露：辽东精锐已损耗，内乱牵制新兵，将领观望，边防与威信同时失灵。  
**问：** 十年前还能开凿两千七百多千米运河，为何十年后连雁门都难保全？  
答链：辽东折损 → 军力滞后 → 内乱抽空 → 威信崩塌。

**【翻页】时间轴「618」→ 616 再下江南 → 618 隋亡**

**讲：**  
616 年，北方已不可收拾，炀帝仍南下江都——这时已不是巡游展示，而是**政治退避**。骁果军多关中人，思乡离心；进言之路关闭。

**618 年**，宇文化及等发动兵变，炀帝被缢杀于江都。同年李渊在长安称帝，建立唐朝。

**教材结论：618 年，隋炀帝在江都被部下杀死，盛极一时的隋朝随之灭亡。**

**讲：**  
罗隐诗：「君王忍把平陈业，只换雷塘数亩田。」与皮日休对读——一叹运河千年之用，一叹统一大业只换坟土数亩。一世功业，所值为何？

**板书：**  
```
612–614 三征高句丽
611 山东起义（徭役）
613 杨玄感
615 雁门
618 江都之变 · 隋亡
```

## 九、总结与课后讨论（约 3 分钟）

**【翻页】时间轴「总结」**

**讲：**  
评价隋朝，要算**两笔账**，不能混成一笔骂倒，也不能只讲辉煌。

**兴的遗产：** 589 统一；开皇户籍财政、三省六部、府兵、开皇律；大运河与漕运；科举取士方向。  

**亡的透支：** 营东都、开运河、筑长城驰道、巡游、三征辽东的高强度征发；编户解体；起义与贵族叛乱；军力滞后、雁门被围；滞留江都、进言断绝。

**收束主问题：**  
三十七年，走完「统一 → 制度化 → 全国工程 → 超常动员 → 系统崩溃」。  
影响千年的是制度与运河这类资产；只活三十七年，是因为把资产当无限信用去透支。

**板书：**  
```
兴：统一 · 制度 · 运河 · 科举
亡：急政 · 徭役 · 征辽 · 离心
结论：遗产可穿越王朝；透支必拖垮王朝
```

**【翻页】时间轴「结束」→ 课后讨论题**

**讲（约 30 秒收束，可下课前说）：**  
回到最初的两个数字：37 与 1300。三十七年，我们讲了统一、制度、运河、科举，也讲了徭役、辽东、雁门、江都。一千三百年，是科举留给后世的时间。  
请记住：历史不仅追问「他做过什么」，还要追问——**代价由谁承担**。

**课后讨论（投影五题）：**

1. 科举制度的创立对当时社会产生了什么影响？  
2. 罗隐诗「君王忍把平陈业，只换雷塘数亩田」——隋炀帝为何落得如此下场？隋朝速亡的原因是什么？  
3. 「尽道隋亡为此河，至今千里赖通波。」若说运河有害，后人为何长期沿用？若说有益，当时百姓又为何深感其害？  
4. （选做）秦、隋都二世而亡，制度又为汉唐所继承。「短命王朝」是灾难还是催化剂？  
5. （选做）用「中书出令—门下审核—尚书执行」说明：若炀帝要强征民夫开凿运河，正常程序应如何？现实中为何失效？
