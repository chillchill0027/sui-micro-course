# 从分立到统一：教学动画

- `统一进程动画.mp4`：1920×1080，15帧/秒，约30秒，无声，可插入PowerPoint。
- `统一进程动画.html`：离线单文件，支持暂停、重播、阶段跳转、拖动进度和全屏。
- `source`：可编辑绘制与视频生成源码。

时间轴：0—4秒三国并立；4—12秒北周灭齐（577年）；12—21秒隋代周（581年，中间交代587年废西梁）；21—30秒隋灭陈（589年）。

全部阶段使用同一底图、坐标、比例与裁切，无镜头移动，领土只改变颜色，政权消失后分界线同步淡出。地图中的邺是定位参照，隋朝阶段不表示它仍是都城。

04.jpg标注572年，作为固定地理底图和疆域概括依据；01.jpg标注612年，用于理解隋朝统一后的总体格局，不直接作为589年的疆域画面。边界以手工折线概括，供微格课说明三次政权变化，不是逐年精确历史GIS复原；未表现577—589年全部局部边界调整、战线或行军路线。
